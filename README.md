# Smart Traffic Management System 🚦

An interactive, responsive frontend dashboard that simulates a smart traffic management system using HTML, CSS, and JavaScript.

## Features

- **Traffic Signal Simulation:** Visualize traffic signals at a four-way intersection.
- **Automatic Mode:** Cycle through traffic signals automatically.
- **Manual Mode:** Select an individual direction to activate its green signal.
- **Emergency Priority:** Simulate priority for emergency vehicles.
- **Pedestrian Crossing:** Simulate pedestrian crossing requests.
- **Live Queue Monitor:** Display simulated vehicle queues for four directions.
- **Traffic Statistics:** Show vehicle count, average queue length, waiting time, and flow efficiency.
- **Responsive UI:** Adapt the dashboard to desktop and mobile screens.
- **Interactive Controls:** Start, stop, reset, and switch between operating modes.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Responsive Web Design
